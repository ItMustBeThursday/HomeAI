# Implementation contract — isolated HomeAI evolution kit

Revision during finish: hosted candidates need no fictional VRAM; local candidates still require measured VRAM. Voice IDs are bounded with fail-closed maxRequests. See CONTRACTS.md and CURRENT-RUNBOOK.md for these explicit contract amendments and their regression tests.
Node >=24, native ESM, no npm dependencies, project-relative .mjs files. This is an additive development kit, NOT a replacement for running plugins or a claim of deployed integration. Read MISSION.md. Avoid touching D:\HomeAIGit or runtime configs. All modules export documented contracts and no side effects on import.

## switch-core.mjs
export createSwitchController(config) returns {handle(event), snapshot()}. config: {deviceIds: array max4 unique strings, mode:'one'|'two', itemIds: nonempty unique string array, debounceMs:integer>=0, scanIntervalMs:positive integer, maxAgeMs:positive integer}. event {deviceId,sessionId,seq,kind:'press'|'release'|'tick'|'disconnect'|'connect'|'override',button:1|2,at:integer,receivedAt:integer}; ticks/override are caregiver/hub local events and must not require device fields. handle returns array of {type:'highlight'|'select'|'feedback'|'reject'|'paused',...}. No network effects. Global selected index initially0; only tick advances in one-button mode; button1 press selects in one mode; two mode button1 advances button2 selects. Release never selects. Edge/debounce per device/button, sequence/session validation, old/duplicate/future/malformed events rejected with no selection. A disconnected device cannot select; explicit reconnect/session resets edge+sequence safely. One held button produces <=1 selection. pause on disconnect, explicit caregiver override {paused:boolean}; no auto-selection on reconnect. Keep memory bounded (4 devices, no unbounded event log), monotonic event time handling. No LLM interpretation.

## model-policy.mjs
export rankCandidates(candidates,request,now), buildContext(items,budget).
candidate {id,roles:array,status:'candidate'|'admitted'|'quarantined',digest,contextTokens,maxOutputTokens,quality:0..1,latencyMs,freeVramBytes,requiredVramBytes,local:boolean}; request {role,inputTokens,outputTokens,minQuality,maxLatencyMs,reserveVramBytes}. Only admitted candidates with valid metrics/digest, supported role, sufficient context/output/VRAM and quality/latency pass. Unknown required metrics exclude (no guessed zero), reject malformed input. deterministic score quality first then latency then id; return [{id,reason,...}] no fake benchmarks. buildContext items {id,text,tokens,required:boolean,priority:number}; budget positive int; retain all required or throw, de-duplicate id (conflicts throw), never truncate required; choose optional highest priority whole items fitting budget, report included/excluded and usedTokens. These are explicit caller token counts, not claimed tokenizer.

## execution-policy.mjs
export validateManifest(manifest), createRunPlan(manifest,context), nextState(state,event).
manifest {version:1,id,projectRoot,steps:[{id,kind:'test'|'build'|'compile',tool:'node'|'npm'|'dotnet'|'cargo'|'cmake',args:string[],timeoutMs}],serve?:{directory,port}}. context {projectRoot,toolPaths:{name:absoluteExecutablePath},allowBuild:boolean,allowServe:boolean}. Reject traversal/absolute serve dirs, UNC/device paths, NUL, shell operators in args, empty/unbounded args, duplicate ids, unbounded timeouts (max300000), unsupported tools. Root must be local absolute and context match; validation is not OS sandbox. npm package scripts/builds execute arbitrary project code: explicitly require allowBuild for all non-test steps and npm/dotnet/cargo/cmake even test. node test only '--test' and safe relative .test.mjs targets (no eval/import/require/preload). Plan commands use resolved executable, args array, shell:false, cwd bounded root, timeout. serve localhost only, no implicit install/network privileges. nextState pure transitions queued->running->passed/failed/cancelled/timed-out, no restart of terminal job, artifact/serve readiness ONLY explicit successful build then independently healthChecked. Export details documented in CONTRACTS.md by code owner.

## voice-core.mjs
export createVoiceSession({maxTextLength=4000}={}) returns {handle(event),snapshot()}; states idle,listening,transcribing,thinking,speaking,error; events start,stopCapture,transcript,response,playbackDone,cancel,disconnect,error each carries requestId except start creates from explicit requestId. Matching request IDs only. New start invalidates prior, stale transcript/response never spoken. transcript {text} -> emit {type:'request',requestId,text}; response {text}-> {type:'speak',requestId,text}; cancel/disconnect -> {type:'stop',requestId} and idle/error no later stale speak. Blank/oversized text rejected; no audio retention/no network on import. Text fallback always available; device switch input does not require child speech.

## Node runner and serving
runtime-runner.mjs exports runPlan(plan,{spawnImpl,clock,...} optional injection) AND serveArtifacts(options) with explicit localhost static serving, path traversal/symlink refusal, no directory listing, MIME, bounded requests, GET/HEAD only; CLI must be separate run-kit.mjs. Actual child processes shell:false, bounded logs, timeout/cancel process cleanup honest Windows descendant limitations, no secret env pass by default beyond explicit essentials, no network/isolation claims. Consume validated plans only (revalidate boundaries, do not trust forged plan). Real browser/compilation checks unavailable in isolated checker. runner.test.mjs may test dependency-injected adapters; tests must NOT spawn servers/processes or write files in isolated checker.
