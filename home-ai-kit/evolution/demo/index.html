HomeAI development workbench

Switch lab

A deterministic input simulator for testing one- and two-switch interaction. No Home Assistant devices or Raspberry Pis are connected.

Caregiver / developer setup

Start focuses the keyboard practice area. One switch: hold Space to test that it selects only once. Two switches: Space means next, Enter selects. Each switch button also supports its own keyboard activation. This preview has not been validated for a child's physical access needs.

What this demonstrates

Switch events are handled by deterministic code. A model does not decide which item a press selects. Disconnect pauses scanning; caregiver resume is explicit. Spoken feedback uses local voices only when the browser reports one available.

Speech capture, Home Assistant commands, deployment to Pis and supervised hardware trials remain separate integration steps.
