    Reaching the service from other devices

    By default it listens on this PC only. Edit config/network.json and restart: set host to 0.0.0.0 (or your Tailscale IP), add names to allowedHosts (e.g. your *.ts.net name) or set allowPrivateIPs for LAN/Tailscale addresses. Shell, agents, config and device management still only work from this PC unless remoteAdmin is true. Easiest private HTTPS: tailscale serve --bg 18850, then add the Tailscale name to allowedHosts. See README, "Network access".
